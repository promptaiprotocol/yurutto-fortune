# 🔮 ゆるっと占い

毎日をちょっと楽しむための、やさしいWeb占いです。

## 主な機能

- 🌞 今日の運勢（恋愛・仕事/勉強・金運・コンディション）
- 🎴 オリジナル「ゆるっとカード」1枚引き
- 🃏 3択占い
- ✨ YES / NO
- 🎂 誕生日占い（星座・数秘・テーマカラー）
- 🎨 ラッキーカラー / 🍰 ラッキーフード / 🔢 ラッキーナンバー
- オフライン対応
- ログイン不要・外部APIなし・広告なし

## プライバシー

入力した質問や誕生日は外部へ送信しません。ブラウザ内で処理します。

## ご利用について

この占いはエンタメとして楽しむためのものです。健康・お金・進路など大切な判断は、占いだけで決めず、信頼できる情報や専門家、自分の気持ちも大切にしてください。
